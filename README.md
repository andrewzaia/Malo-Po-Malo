# Malo po malo 🇷🇸

**Learn Serbian, little by little.** A friendly, self-paced place to build your Serbian skills, from your first words to short everyday conversations.

### 👉 [Start learning Serbian](https://andrewzaia.github.io/Malo-Po-Malo/)

**[Open the learning website →](https://andrewzaia.github.io/Malo-Po-Malo/)**

No downloads, installation or account required. Open the site in your browser and practise on your phone, tablet or computer.

## What you'll learn

Malo po malo has three progressive learning levels:

| Level 1 · Beginner | Level 2 · Intermediate | Level 3 · Advanced |
| --- | --- | --- |
| The alphabet, numbers and first words | Questions, routines and familiar conversations | Opinions, debate and nuanced replies |
| Pronouns and forms of “to be” | Plans, invitations and past events | Verb aspect, conditional forms and cases |
| Basic greetings and introductions | Sentence building and guided exchanges | Problem-solving, reading comprehension and negotiations |

Start with the fundamentals and move on when you feel ready. The shorter labels in the website's level selector keep all three options comfortable on mobile and desktop screens.

## Learn your way

- **Reference cards:** Study useful Serbian words, phrases and model answers, with translations and revealable explanations.
- **Quick quizzes:** Test what you know in short, five-question rounds with immediate feedback.
- **Type & practise:** Build recall by writing the answers yourself.
- **Build sentences:** Arrange words into complete Serbian sentences in Intermediate and Advanced lessons.
- **Guided conversations:** Practise responding to everyday questions and exchanges.
- **Advanced Serbian:** Work on opinions, aspect, conditionals, case forms, problem-solving, reading inference, expressions and negotiations through 8 further lessons.
- **Latin and Cyrillic:** Switch between Serbia's two writing systems as you learn.
- **Daily practice:** Mix a few exercises into a manageable routine.

### Want a bigger challenge?

The **Testing** section offers a 100-question timed assessment based on your selected level, with up to **60 seconds per question**. If you have a test access word, you can complete the assessment, review your answers and save your results as a **PDF**.

## How to get started

1. **[Visit Malo po malo](https://andrewzaia.github.io/Malo-Po-Malo/).**
2. Choose **Level 1 (Beginner)**, **Level 2 (Intermediate)** or **Level 3 (Advanced)**.
3. Select a lesson from the menu.
4. Start with **Reference cards**, then try a **Quick quiz** or **Type & practise**.
5. Return regularly and build confidence a little at a time.

**A little each day adds up. Malo po malo.**

## Good to know

- The course uses common **Ekavian Serbian** forms.
- Pronunciation hints are approximate English-language guides, not recorded audio.
- Practice answers are checked against taught examples and accepted alternatives; the site is not a free-form conversation tutor or formal proficiency certificate.
- Completed lesson-round progress and recent lesson preferences are saved in your browser when supported. Your progress is specific to that browser and device.
- An active timed test will reset if you reload or close the page, so download your PDF report when you finish.

## About the project

Malo po malo is a browser-based learning project hosted on GitHub Pages. It is designed to make regular language practice approachable, with short lessons, repetition and immediate feedback.

Found an issue or have an idea for improvement? [Share feedback on GitHub](https://github.com/andrewzaia/Malo-Po-Malo/issues).

<details>
<summary><strong>For developers and contributors</strong></summary>

This is a static HTML, CSS and JavaScript website. There is no application server, database, build step or API key requirement.

To run locally, clone or download this repository and open `index.html` in a browser. The site is published through GitHub Pages.

Lesson content lives in `data.js`, `intermediate.js`, `intermediate-bank.js` and `advanced.js`. The optional developer checks can be run with:

```sh
node --test tests/*.test.cjs
```

The timed-test access word is configured client-side, so it is not secure authentication.
